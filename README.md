🤖 Which AI Tool Is Right for You?
A bilingual interactive web application that helps users discover which category of AI tool best matches their needs through a short 14-question assessment.
The application is designed for students, graduates, employees, entrepreneurs, and anyone who wants to understand which type of AI tool may be most useful for their goals.


⸻


🌟 Features
• 📝 14-question AI assessment
• 🌐 Bilingual support: Arabic 🇸🇦 and English 🇬🇧
• ↔️ RTL/LTR layout switching
• 📊 Progress indicator
• ⬅️➡️ Next / Previous navigation
• 🎯 Personalized AI tool category recommendation
• 💾 LocalStorage support to preserve the user’s progress/results
• 🔄 Start Over functionality
• 📱 Responsive design for desktop, tablet, and mobile
• ℹ️ About the Test section explaining the assessment


⸻


🧠 How It Works
The user goes through a 14-question assessment about their needs, interests, and intended use of AI tools.
The application analyzes the user’s answers and calculates the most suitable AI tool category.
At the end, the user receives a personalized recommendation based on their responses.
User Flow
Landing Page
      ↓
Start Assessment
      ↓
14 Questions
      ↓
Answer Analysis
      ↓
Results Page
      ↓

🌍 Language Support
The application supports two languages:
• 🇬🇧 English
• 🇸🇦 العربية
The interface automatically adjusts between:
• LTR — Left-to-Right for English
• RTL — Right-to-Left for Arabic
Users can switch between languages while using the application.


⸻


🎯 Recommendation System
The recommendation system evaluates the user’s answers and determines which AI tool category best matches their needs.
The result is generated based on predefined scoring and recommendation rules.
This allows users to receive a simple and understandable recommendation rather than choosing an AI tool randomly.


⸻


💾 LocalStorage
The application uses the browser’s LocalStorage to save relevant assessment information locally.
This supports features such as:
• Preserving user answers
• Remembering assessment progress
• Displaying previous results
• Starting the assessment over when requested
No account or server-side database is required for the assessment experience.
